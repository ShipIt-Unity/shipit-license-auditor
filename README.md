ShipIt License Auditor helps Unity teams review third-party license and attribution information in a project. See the [product overview](FEATURES.md) and [version-history record](CHANGELOG.md).

## Product overview

[![Full License Auditor marketing artwork (1950 × 1300)](product-marketing-overview.png)](product-marketing-overview.png)

### How it fits

```mermaid
flowchart LR
    A[Unity project materials] --> B[ShipIt License Auditor review]
    B --> C[License and attribution information for human review]
    C --> D[Your team checks obligations and makes its release decision]
```

The tool helps teams see third-party materials and organize license and attribution information. It supports human review; it does not decide whether a use is legally permitted.

This page does not state a current package version or availability. Check the current website and publisher page before purchase.

## Important boundary

License findings are informational and do not replace legal advice or a project-specific legal review. Review source license notices and your intended use before shipping.
