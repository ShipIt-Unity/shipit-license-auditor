# ShipIt License Auditor — feature overview

This brief overview describes the product at a marketing level. It does not disclose source code, implementation details, or complete technical documentation.

- **Project visibility:** help teams understand third-party materials present in a Unity project.
- **Review support:** organize license and attribution information for human review.
- **Team handoff:** prepare clearer records to support a team's release review.

The tool supports review; it does not decide whether a use is legally permitted. See the website and product documentation for current scope.
